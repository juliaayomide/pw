
# 📍 Projeto Busca CEP

## 📌 Sobre o projeto

Este repositório contém um **projeto simples de Busca CEP**, desenvolvido com o objetivo de praticar **JavaScript** e o consumo de **APIs**.

O projeto permite que o usuário informe um **CEP** e, a partir disso, o sistema realiza uma consulta em uma API para retornar informações como rua, bairro, cidade e estado.

---

## 🧠 Objetivo do projeto

O principal objetivo deste projeto é:

- Introduzir o consumo de APIs em JavaScript  
- Trabalhar com requisições HTTP  
- Praticar a manipulação de dados retornados pela API  
- Desenvolver a interação com o usuário  
- Fixar conceitos básicos de JavaScript na prática  

---

## ⚙️ Funcionamento

O funcionamento do projeto é simples:

1. O usuário informa um CEP  
2. O JavaScript faz uma requisição para uma API de consulta de CEP  
3. A API retorna os dados do endereço  
4. As informações são exibidas na tela de forma organizada  

Esse fluxo ajuda a entender como aplicações se comunicam com serviços externos.

---

## 🛠️ Tecnologias utilizadas

- JavaScript  
- HTML  
- CSS  
- API de consulta de CEP  

---

## 🎯 Conclusão

O projeto Busca CEP é um ótimo exemplo de aplicação simples e funcional, sendo ideal para iniciantes que desejam entender como integrar JavaScript com APIs externas e tornar aplicações mais dinâmicas e interativas.
